# accessibility — 图标无障碍规范

## error 级别硬约束

### 1. 装饰性图标必须对辅助技术隐藏

纯装饰用途、不传达任何语义信息的图标，必须在 SVG 根元素上设置 aria-hidden="true"，使其被屏幕阅读器等辅助技术忽略。

装饰性图标的判断标准：移除该图标后，用户仍能通过相邻的可见文本理解全部信息。

### 2. 语义图标必须提供文本替代

承担语义传达的图标（如无相邻文本的独立操作按钮、状态指示器等），必须通过以下方式之一提供文本替代：

- title 和 description 子元素：为 SVG 添加 <title> 和 <desc> 子元素，提供图标的名称和描述。title 作为简短标签，desc 作为详细描述。
- aria-label 属性：直接在图标组件上设置 aria-label 属性，适用于无法在 SVG 内部添加子元素的场景。
- 相邻的可见文本：图标旁边有可见的文本标签，且两者通过 aria-labelledby 显式关联。

语义图标不得使用 aria-hidden="true"。

### 3. 交互式图标必须可键盘操作

可作为按钮、链接等交互元素的图标，必须：
- 具备可聚焦性（通过 tabindex 或使用语义化 HTML 标签如 button）
- 响应键盘事件（Enter 和 Space 键）
- 在聚焦时显示可见的焦点指示器
- 提供操作名称（通过 aria-label 或内部文本）

不得使用 div 或 span 配合 onClick 实现交互图标。

### 4. 图标颜色必须有足够对比度

图标作为信息传达元素时，其颜色与背景的对比度必须满足 WCAG AA 级标准（至少 4.5:1）。图标作为装饰性元素或与相邻文本配对使用时不受此限制。

## warn 级别软约束

- 图标尺寸不小于 24x24 CSS 像素（触摸目标的最小推荐尺寸）
- 图标间距不小于 8px，避免误触
- 加载状态图标使用 aria-live="polite" 或 role="status" 通知辅助技术
- 图标符号的含义在整个应用中保持一致（同一图标不代表不同含义）
