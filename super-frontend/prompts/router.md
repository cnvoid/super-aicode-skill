# router — 路由规范

## error 级别硬约束

### 1. 需要认证的路由必须有全局路由守卫

对于需要登录后才能访问的页面，必须在路由配置中通过 meta 字段标记认证要求，并在全局路由守卫中统一拦截未认证的访问，跳转到登录页。

路由守卫不得分散在各个页面组件的 onMounted/useEffect 中逐个判断。全局守卫是唯一的认证拦截入口。

### 2. 页面级路由必须使用懒加载

除首页和登录页外，所有页面级路由组件必须使用动态导入语法实现懒加载，减少首屏打包体积。不得将所有页面组件在路由配置中静态 import。

## warn 级别软约束

- 面包屑数据根据路由层级自动生成，通过路由 meta.title 配置
- 路由跳转参数使用 query 或 params 传递，不得使用 localStorage 或全局 Store 作为页面间参数传递方式
- 多级路由嵌套不超过 3 层
- 404 页面作为通配符路由放在路由表最后
- 权限路由按角色动态生成，后端返回权限树，前端据此过滤可访问路由
